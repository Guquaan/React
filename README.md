# 这个项目主要是给自己学习react的
1. 项目结构
    eslint.config.js: eslint的配置文件，主要是为了配置eslint的规则
    package.json: 项目的配置文件，主要是为了配置项目的依赖
    src: 项目的源代码目录，主要是为了存放项目的源代码
    public: 项目的静态资源目录，主要是为了存放项目的静态资源
    dist: 项目的构建目录，主要是为了存放项目的构建输出
    vite.config.js: 项目的vite配置文件，主要是为了配置vite的构建选项，项目底层化配置
2. 项目依赖
    eslint: 项目的eslint依赖，主要是为了配置eslint的规则
    @vitejs/plugin-react: 项目的vite插件，主要是为了配置vite的react插件
    @vitejs/plugin-react-swc: 项目的vite插件，主要是为了配置vite的react-swc插件
    swc: 项目的swc依赖，主要是为了配置swc的编译器
    -- 后续还会继续进行添加的
3. 技术支持
    · 数据定义
    · 组件
    · 列表遍历
