## 完成：基于矢量数据库的人脸识别系统（大四毕设 / 课程项目）

在已有 React 学习框架（react-demo）基础上，补全并验证了完整的人脸识别系统。

### 技术选型
- 前端：React 19 + Vite，hash 路由、零额外 UI 依赖（组件 Webcam/QrScanner/ImageInput/ui）
- 后端：Python FastAPI，严格分层 api → service → (repository, engine)
- 矢量库：ChromaDB（默认）+ 内置 LocalVectorRepository(NumPy+SQLite) 兜底，可切换
- 人脸：ArcFace ONNX（YuNet 检测 + w600k_mbf 轻量模型 13MB），MockEngine 离线联调
- 二维码：后端 HMAC 签名 token + qrcode PNG，扫码落审计日志
